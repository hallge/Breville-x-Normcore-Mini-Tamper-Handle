Breville Dual Boiler (BDB) Magnetic Tamper Handle for Normcore v4 by vickeryj on Thingiverse: https://www.thingiverse.com/thing:5976291

Summary:
I was always sad that the built in tamper slot on my espresso machine went to waste.I finally got a 3d printer, and decided to see if I could make a replacement handle for my Normcore v4 Tamper to stick it in the slot, and here we are.I used the threads-scad library for the threads: https://github.com/rcolyer/threads-scadAnd the Chamfers-for-OpenSCAD for the chamfer: https://github.com/SebiTimeWaster/Chamfers-for-OpenSCAD
